# 🚀 AI-Powered Video Transformation App

Transform your videos with **just a few clicks** using the power of **Generative AI**. This project leverages **Fal AI’s Hunyuan-Video model**, integrates **Uploadcare**, **Cloudinary**, and **MongoDB**, and delivers a full-stack experience with **Node.js + React** — built and deployed in under 24 hours!

🌐 **Live App**: [Try it here](https://stupendous-llama-0c675a.netlify.app/)  
🎥 **Sample Output Video (MP4)**: [Watch on Google Drive](https://drive.google.com/file/d/1w9FVjwrDqfK8u0g2om67uJjJCngzo80q/view?usp=drive_link)

## 🧠 Project Overview

This is not just a project — it’s proof that with the right tools and mindset, you can go from **idea to execution in 24 hours**. The app allows users to:

- 🎥 Upload videos via Uploadcare
- 🛠️ Choose transformation parameters
- 📡 Send video to Fal AI (Hunyuan-Video model)
- 🔁 Receive the processed video asynchronously via webhook
- 💾 Store and view history (MongoDB)
- 🔗 Download the final video — all within the same UI

> 🚨 No mockups. No theory. Just functional AI in action — built, tested, and deployed!

## 🛠️ Tech Stack

- **Frontend**: React + Vite + Uploadcare
- **Backend**: Node.js + Express + MongoDB + Axios
- **Cloud Services**: Cloudinary (video storage), Uploadcare (file input)
- **AI Model**: Fal.ai — Hunyuan-Video API
- **Dev Tools**: Netlify (deployment), Vite (build system)
